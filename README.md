# Полюс — консоль управления облаком

Демонстрационная консоль управления облачной платформой, построенная целиком на [Taiga UI v5](https://taiga-ui.dev) (Angular 20, standalone-компоненты, signals).

## Разделы

- **Обзор** — потребление по месяцам, загрузка CPU самой нагруженной ВМ, квоты проекта, лицевой счёт, последние события.
- **Виртуальные машины** — таблица с фильтрами (статус, регион, поиск по имени/IP), пагинация, запуск/остановка/перезапуск/удаление с подтверждением, создание ВМ через диалог.
- **Хранилище** — S3-бакеты: класс хранения, занятая квота, цена, создание и удаление.
- **Биллинг** — начисления по месяцам, прогноз текущего месяца, операции по лицевому счёту, пополнение.
- **Доступы** — пользователи и роли, приглашения, отзыв доступа.
- **Журнал событий** — аудит действий по серьёзности с фильтрами.

Все действия изменяют общее состояние (signal-стор) и попадают в журнал событий и уведомления в шапке.

## Запуск

```bash
npm ci
npm start          # dev-сервер на localhost:4200
npm run build      # production-сборка
```

## Решения против шаблонного вида

- Акцент темы переопределён с дефолтного сине-индиго на тёмно-бирюзовый (`src/styles.scss`).
- Плотные таблицы вместо сетки одинаковых карточек; моноширинный шрифт для IP, идентификаторов и endpoint-ов.
- Данные консистентны: суммы складываются из пресетов и дисков, события журнала ссылаются на реальные ресурсы.
- Тёмная тема — переключатель в шапке, состояние сохраняется в localStorage.
